# urusaqqrun/tap

Homebrew tap for [JarvisVoice](https://jarvis-voice.com): always-on voice typing for Mac. Talk, and it types into the app you're using.

```bash
brew install --cask urusaqqrun/tap/jarvis-voice
```

Apple Silicon, macOS 14 or later. JarvisVoice updates itself from its menu, so `brew upgrade` skips it unless you pass `--greedy`.

`Casks/jarvis-voice.rb` is generated by `app/package.sh` in [urusaqqrun/jarvis-voice](https://github.com/urusaqqrun/jarvis-voice) for each release.
